## Key Concepts

### Sample Spaces and Events

**Sample Space (Ω)**: The set of all possible outcomes of an experiment.

**Event**: A subset of the sample space.

### Probability Axioms

1. For any event A, P(A) ≥ 0
2. P(Ω) = 1
3. If A₁, A₂, ... are disjoint events, then P(⋃ᵢAᵢ) = ∑ᵢP(Aᵢ)
